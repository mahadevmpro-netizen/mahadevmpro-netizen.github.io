Bremerhaven: Infrastructure Mapping and Geospatial Data Management

An independent demonstration project using OpenStreetMap data in Bremerhaven, Germany. Road areas, infrastructure assets, curbs, drainage channels and traffic signs were mapped and organised into a structured GeoPackage with consistent attribute schemas and a print-ready map output.

Automated GIS QA/QC Tool

A Python tool that checks a five-layer GeoPackage against written rules. Validation rules live in a JSON file, and every run produces a CSV and an HTML report. On the current dataset all 45 checks pass; on an older backup copy the tool flags three invalid material values.
