Bremerhaven: Infrastructure Mapping and Geospatial Data Management

An independent demonstration project using OpenStreetMap data in Bremerhaven, Germany. Road areas, infrastructure assets, curbs, drainage channels and traffic signs were mapped and organised into a structured GeoPackage with consistent attribute schemas and a print-ready map output.

Independent demonstration project — not client work or an official infrastructure inventory.

Automated GIS QA/QC Tool

A Python-based GIS quality-checking workflow developed to validate geospatial datasets using configurable rules. The tool separates validation settings into a JSON configuration file and executes checks through a Python script.

The workflow generates a CSV report showing individual check results, making it easier to review validation outcomes beyond terminal messages.

  • Python
  • GeoPandas
  • JSON
  • CSV Reporting
  • GIS QA/QC
  • GitHub

Independent learning and portfolio project. Validation coverage is limited to the checks implemented in the tool.

DEM-Based Terrain and Suitability Analysis

A raster analysis workflow using a Digital Elevation Model in QGIS. The work includes terrain derivatives and classification outputs to explore how elevation and slope conditions can contribute to suitability assessment.

Processing outputs include slope, aspect, hillshade, contour generation, elevation suitability and slope suitability layers, followed by a weighted overlay exercise.

  • QGIS
  • DEM
  • Raster Analysis
  • Slope and Aspect
  • Reclassification
  • Weighted Overlay

Independent technical learning project. Suitability results demonstrate a GIS workflow and should not be interpreted as a validated site-selection recommendation.
